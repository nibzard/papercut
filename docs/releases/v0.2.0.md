# Papercut v0.2.0

Papercut now records where agents struggle to use a product chosen by the task.

- Require `--product` on new reports. Optional `--product-version` and
  `--surface` keep version and usage context with each observation.
- Gather one product's reports across consuming repositories with
  `list`, `render`, and `triage-pack --product <id>`.
- Preserve v0.1 reports as unattributed history. Broad failed-command capture
  is suspended; `sweep` and stale hook calls no longer record signals.
- Preserve stowed instruction and settings symlinks during `install` and
  `uninstall`; retire Papercut's old failed-command hook.

Upgrade from v0.1.0 by replacing the binary, then run `papercut install --yes`
and `papercut doctor`. Restart agent sessions so they read the new instructions.
New reports need an explicitly designated product:

```sh
papercut add --product my-sdk -- 'The quickstart omitted the initialization step'
```

Install the released package with `cargo install papercut-cli --version 0.2.0
--locked`. The executable is `papercut`.
