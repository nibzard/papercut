# Full-project review — 2026-08-06

A three-dimension review (capture path/store, install/managed-blocks/doctor,
CLI contract/read commands) found 1 critical, 9 major, and a set of minor
defects. The fix pass is one conventional commit per phase; status is tracked
inline. `cargo test && cargo clippy --all-targets -- -D warnings &&
cargo fmt --check` is green after every phase.

## Critical

- **C1 — Claude Code hook recorded nothing in production.** `hook.rs` parsed
  `/tool_result/exit_code`, a shape the harness never sends. Verified live
  (Claude Code v2.1.223): failures fire `PostToolUseFailure` with a top-level
  `error` string; `PostToolUse` fires only on success. Fix: content-based
  parser off the `error` field; install wires `PostToolUseFailure`; rerun
  heals a legacy `PostToolUse` install. **Fixed — Phase 1.**

## Major

- **M1 — Codex sweep lost parallel-session data.** Single-path watermark skipped
  any file sorting before `last_path`. **Fixed — Phase 2** (per-file
  `FileMark` watermarks).
- **M2 — Watermark persistence failure was swallowed → unbounded duplicates.**
  **Fixed — Phase 2** (atomic `write_sweeps`; failure escalates to exit 1).
- **M3 — Lib unit tests could write into the real store.** Three private env
  mutexes. **Fixed — Phase 3** (one shared `EnvGuard`, save/restore).
- **M4 — Duplicate managed blocks leaked body text; uninstall orphaned it.**
  **Fixed — Phase 4** (the engine owns every complete begin..end region).
- **M5 — Harness config-path drift orphaned blocks; uninstall/doctor ignored
  the recorded path.** **Fixed — Phase 4** (consult `config.json`).
- **M6 — Doctor called a drifted-matcher hook healthy.** **Fixed — Phase 4**
  (`hook_status` checks `matcher == "Bash"`).
- **M7 — Unquoted hook command broke on a spaced exe path.** **Fixed — Phase 4**
  (`hook_command` shell-quotes).
- **M8 — `is_our_hook` substring match could delete a user's hook.** **Fixed
  — Phase 4** (anchored trailing-token match).
- **M9 — Event text forged markdown structure in list/projection/triage-pack.**
  **Fixed — Phase 5** (`md_single_line`, `md_indent_continuation`,
  `md_code_span`).

## Minor (Fixed — Phase 6 unless noted)

- `--yes` is now a required gate on `install` (exit 2 without it). **Phase 4.**
- `cargo fmt` drift on `claude_code.rs`. **Phase 1.**
- Pre-clap `_hook` intercept: a malformed hook invocation no longer reaches
  clap (exit 2 + stderr).
- Unknown `--harness` id → exit 2 `unknown_harness` across sweep/install/uninstall.
- `--repo` filter normalizes (`.git` URL / absolute path) before matching.
- Doctor-unhealthy JSON envelope now `status: "error"` + `unhealthy` item,
  agreeing with exit 1.
- Atomic writes for `config.json` and `render --write` (temp + rename).
- Orphaned `.tmp` files reported by `doctor` (never deleted).
- Store dirs created `0700` on unix.
- `parse_rfc3339_unix` clamps pre-epoch to 0; rejects out-of-range fields.
- Dead `Cluster.exits` field removed.
- Managed-block trailing-newline round-trip documented as an accepted
  limitation (Phase 4).

- `cargo fmt --check`: clean.
- Live e2e of C1: a real failed Bash command in a real Claude Code session
